# Hold implementation

Stay in a discussion phase. Clarify the goal and constraints, and inspect relevant code and existing patterns when the task involves a codebase. Ask focused questions about decisions that would materially change the approach.

Work through viable approaches and their tradeoffs with the user. Recommend a direction grounded in what you found, and summarize any unresolved decisions.

Stop after presenting the approach for review. Begin implementation only when the user explicitly asks you to proceed.
